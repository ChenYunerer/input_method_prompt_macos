# 中英提示 · 工程说明

完整功能介绍、安装步骤、设置总表与自动构建下载见 [仓库 README](../README.md)。

产品与设计文档：[PRD](docs/PRD.md) · [技术方案](docs/TECHNICAL_DESIGN.md)。

原生 macOS 菜单栏小工具。在系统输入源或 Caps Lock 状态切换后，在屏幕中央显示「中 / 中文输入」「a / 英文小写」或「A / 大写锁定已开启」。用 0.12 秒淡入，完整显示 0.5 秒，再用 0.18 秒平滑淡出。连续切换会从当前透明度平滑恢复显示并重新计时，不会先消失再重现。

## 使用

1. 双击项目根目录下的 `dist/中英提示.app` 即可运行，也可以把它拖到「应用程序」。
2. 按系统已经配置的中英文切换键，例如 Caps Lock（启用中英文切换时）、地球键或 Control + Space。
3. 菜单栏显示当前状态，菜单仅保留「显示当前输入法」「设置…」「退出中英提示」。手动显示当前输入法不会切换输入法。
4. 打开「设置…」，按场景选择分类：

| 分类 | 配置与操作 |
| --- | --- |
| 切换提示 | 启用开关、背景透明度、中央样式预览、预览切换提示、恢复默认外观 |
| 全屏常驻 | 启用开关、背景透明度、提示大小、展示位置、实际大小样式预览、恢复默认外观 |
| 鼠标跟随 | 启用开关、整体透明度、提示大小、静止时长、隐藏/淡化策略、实时预览、恢复默认外观 |
| 通用 | 登录时自动启动、登录项状态与系统设置入口 |

三种提示独立控制，开关和外观自动保存。关闭切换提示仍可手动预览。切换提示默认背景透明度 22%；全屏常驻默认透明度 45%、大小 100%（75%–500%，步进 5%）。每组「恢复默认外观」只恢复该组的外观，不改变展示位置、启用开关或登录项。全屏常驻窗口在进入全屏时显示、退出后隐藏，鼠标可穿透。鼠标移入常驻图标时，文字和背景会一起淡化，移开后恢复原有外观。

Caps Lock 开启和关闭都会提示；关闭后显示当前输入法。Shift 临时大写不弹提示，以免组合快捷键及普通打字不断触发。若 Caps Lock 已设为中英文切换键，短按按实际输入源变化提示，真正进入大写锁定时显示「A」。

中央与全屏提示使用系统毛玻璃和圆角遮罩，三处提示均无描边和窗口阴影，跟随系统浅色/深色外观。默认背景透明度为 22%（遮罩不透明度 78%），可以在设置中修改。首次打开会展示一次当前状态提示。提示不抢焦点，鼠标点击可以穿透；多显示器时显示在鼠标所在屏幕中央，也可随当前桌面显示。是否在特定全屏应用上可见需要在对应应用实测。

无需辅助功能、输入监控或屏幕录制授权，不采集按键或输入内容，不联网。不更改系统快捷键，仅在你操作自动启动开关时注册或取消登录项。

自动启动使用 macOS 13+ 原生 [SMAppService.mainApp](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp)，按系统实际状态显示，不只保存本地勾选值。如果显示「等待系统允许，暂未生效」，点击「打开登录项」前往系统设置确认。开关亮起但提示待允许时，表示注册请求已存在，并不代表已经生效；可以关闭开关取消。建议将应用放在固定位置（例如「应用程序」）后再开启。自动化测试使用模拟服务验证开启、关闭、失败回退、待允许状态和系统状态同步，不修改真实登录项；没有执行注销或重启系统的端到端测试。

## 本地构建与验证

应用图标源文件位于 `app/Assets/AppIcon.png`，生成方式及设计提示词见 [Assets/README.md](Assets/README.md)。构建脚本会生成包含 16–1024 像素标准/Retina 尺寸的 `.icns`，写入应用包；修改源图后重新构建即可更新图标。菜单栏仍显示实时输入状态。

需要 macOS 13+ 与 Xcode Command Line Tools（Swift 5.9+），没有第三方依赖。构建产物对应当前机器架构。工程文件均在 `app/` 中；以下命令从项目根目录执行，应用仍输出到根目录的 `dist/`。

```sh
bash app/scripts/build-app.sh
bash app/scripts/test.sh
"dist/中英提示.app/Contents/MacOS/InputMethodPrompt" --self-test
"dist/中英提示.app/Contents/MacOS/InputMethodPrompt" --diagnose
open "dist/中英提示.app"
```

`--self-test` 实际显示提示，验证淡入、停留后淡出、动画过程中再次切换的透明度连续性，以及前台应用保持不变；不会更改系统输入法。测试脚本还注入 Caps Lock 状态变化，覆盖大小写切换、重复状态去重。应用使用本机临时签名，未进行 Apple 公证。

真实系统输入法通知测试：`TEST_SYSTEM_INPUT_SWITCH=1 bash app/scripts/test.sh`。此测试会短暂切换输入法并恢复，运行期间请暂停打字。测试脚本直接编译项目源码，无需 XCTest、Swift Testing 或完整 Xcode。

## 检测范围

使用 Carbon 的 `TISCopyCurrentKeyboardInputSource` 读取实际输入源，订阅 `kTISNotifySelectedKeyboardInputSourceChanged`，不根据按键猜测切换结果。系统自带「简体拼音 ↔ ABC」是本工程的目标场景。通过菜单切换或应用自动切换输入源时也会提示。

Caps Lock 通过 `CGEventSource.flagsState(.combinedSessionState)` 每 80 毫秒读取修饰键状态，独立于输入源通知；不读取具体按键。状态表说明见 [Apple CGEventSourceStateID](https://developer.apple.com/documentation/coregraphics/cgeventsourcestateid)。

输入源与 Caps Lock 更新会合并后再显示：普通变化需稳定 100 毫秒，大写锁定开启需稳定 250 毫秒，并在显示前重新读取状态，过滤中英文切换过程中的短暂大写标志。等待状态确认不计入浮层的 0.5 秒显示时长。回归测试覆盖通知先后顺序、短暂大写恢复、真实锁定保持及最终状态复核。

部分第三方输入法用 Shift 切换内部中英文模式，却不改变系统输入源或发送系统通知；这种模式不在当前支持范围内。其他语言显示自己的标识，无法判断的输入源显示键盘标识，不冒充英文。

界面采用 AppKit 的非激活 `NSPanel`。参考：[Apple NSPanel](https://developer.apple.com/documentation/appkit/nspanel)。输入源 API 以本机 SDK 的 `HIToolbox.framework/Headers/TextInputSources.h` 为准。

## 全屏常驻提示

每个检测到全屏窗口的显示器都有独立标识，默认大小 36 × 36 pt，文字、背景与圆角可等比例缩放；调整即时生效并自动保存。默认右上角，可选择九宫格位置（四角、四边中点、中央），贴边时保留 18 pt 安全边距。状态复用已有防闪确认结果；进入全屏时立即读取已确认状态，不需要再次切换输入法。普通轮询周期 0.75 秒，并响应桌面切换、应用激活、屏幕变化和唤醒通知。

全屏判断使用 [CGWindowListCopyWindowInfo](https://developer.apple.com/documentation/coregraphics/cgwindowlistcopywindowinfo(_:_:)) 返回的窗口几何信息，不截图、不读取窗口标题，也不调用私有 Space API。覆盖整个显示器（或刘海下方安全区域）的无边框视频、演示窗口也会显示标识。Chrome 全屏工具栏与内容拆成多个窗口时，会合并同进程、全宽且连续的顶部区域进行识别。该方式不是其他应用原生全屏标志的精确查询：隐藏菜单栏和 Dock 后恰好铺满屏幕的普通窗口也可能被识别，分屏组合和特殊游戏全屏需另行验证。

实际原生全屏验收可运行 `TEST_FULLSCREEN=1 bash app/scripts/test.sh`，测试会短暂打开独立测试窗口并进入/退出全屏，结束后关闭窗口、恢复之前的前台应用。常规测试不切换系统全屏桌面。


## 鼠标跟随提示

默认在鼠标旁显示当前「中 / a / A」，在普通桌面和全屏均跟随移动。默认标识为 27 × 27 pt，可在设置中调整大小（50%–300%，默认 100%）和整体透明度（0%–100%，默认 50%，越大越淡），实时预览并自动保存。优先在右下方，靠近边缘自动换侧；保持点击穿透、不抢焦点。设置 → 鼠标跟随可单独关闭并保存，关闭后移除鼠标移动监听。它跟随鼠标指针，不跟随文字插入光标。

鼠标跟随采用事件驱动，macOS 14+ 按屏幕刷新节奏同步移动、跨屏自动适配，首次移动即时响应，静止后暂停刷新；macOS 13 使用事件合并计时器兼容路径。标识使用轻量半透明背景，减少动态毛玻璃和重复窗口刷新带来的卡顿。

移动期间按屏幕刷新读取实际鼠标位置，减少鼠标事件晚到造成的漏跟；边缘换侧增加 12 pt 恢复余量，避免在阈值附近反复左右或上下跳动。

三处提示统一为圆角正方形：切换提示 148 × 148 pt，全屏常驻默认 36 × 36 pt，鼠标跟随默认 27 × 27 pt。

鼠标指针隐藏时，跟随标识同步隐藏。在设置 → 鼠标跟随中可设置「静止时长」（1–60 整数秒，默认 3 秒）与「静止后」隐藏（默认）或淡化；淡化至当前不透明度的 20%。显示/恢复淡入 0.12 秒，隐藏/淡化 0.18 秒，快速反向从当前透明度连续衔接。可见性以 0.1 秒周期检测。指针可见性接口在本机已验证；若系统不提供该旧接口，设置页会提示，静止功能仍生效。

性能与稳定性优化、调用计数对比及验证边界见 [专项记录](docs/PERFORMANCE_STABILITY.md)。静止隐藏后会暂停指针可见性检测，移动或修改设置时恢复；相同样式配置复用渲染内容，输入源短暂读取失败会自动重试恢复。

鼠标跟随标识隐藏或静止淡化时，输入法/大小写切换会临时淡入显示新状态，停留 0.5 秒后恢复当时的隐藏/淡化策略，不重置静止时长。连续切换会延长显示；关闭跟随或整体透明度为 100% 时不唤出。


## 自动构建与打包

每次 `main` / `master` push，由 [工作流](../.github/workflows/build-release.yml) 构建最终提交的 Apple Silicon 与 Intel 应用；常规回归、签名与 ZIP 校验通过后发布 [GitHub Releases](https://github.com/ChenYunerer/input_method_prompt_macos/releases)。

- `scripts/package-release.sh`：复用本地构建脚本，在临时目录生成应用；输出版本化 ZIP、构建元数据与 SHA-256 到 `dist/releases/`。
- `scripts/publish-release.sh`：用于 CI，校验两个架构的版本、源码提交、批次和校验和，再上传 Release 附件并发布。需要工作流注入 GitHub 上下文及 `GH_TOKEN`。
- 应用版本 / 构建号仍由 `build-app.sh` 的 Info.plist 字段维护；CI 批次与提交 SHA 区分持续构建，不自动改写源码中的版本。
- 图形集成测试需在本机按需执行；CI 执行常规回归，不切换真实系统输入源、全屏桌面或指针可见性。
